    {% endif %} {%- comment -%} `article.link` es el único valor de este widget que llega de un feed RSS ajeno y termina dentro de un atributo navegable del HTML publicado. Un feed hostil o comprometido puede emitir `javascript:` o `data:text/html;…`, y `rel="noopener noreferrer"` no filtra esquemas: sólo limita el acceso a `window.opener` y el Referer. Por eso el enlace se emite únicamente si el esquema está en la allowlist http/https, y con `escape` encima para que el valor no pueda cerrar el atributo y abrir uno nuevo. Si no pasa, se conserva el titular como texto plano: perder el enlace de un feed que emite basura es preferible a hornearlo en el sitio. La misma comprobación existe en scripts/fetch_news.py, que es donde el dato entra; aquí se repite porque _data/feedly_news.json también puede llegar de un commit anterior o de una ejecución previa del script. {%- endcomment -%} {%- assign link_probe = article.link | default: "" | strip | downcase -%} {%- assign link_scheme_https = link_probe | slice: 0, 8 -%} {%- assign link_scheme_http = link_probe | slice: 0, 7 -%} {% if link_scheme_https == "https://" or link_scheme_http == "http://" %} {{ article.display_title | default: article.title | escape }} {% else %} {{ article.display_title | default: article.title | escape }} {% endif %}
