{%- comment -%} Selector ES/EN. Vive en el masthead, junto al conmutador de tema. Antes exigía `page.permalink` y por eso desaparecía de la portada: el home declara `translation_languages: [es, en]` pero **no** tiene permalink —lo omite a propósito, para que jekyll-paginate no pise la página 1 con la 2—. La condición lo dejaba fuera justo en la página donde más se nota. Ahora la ruta sale de `page.permalink` cuando existe y de `page.url` cuando no, que es el caso del home. Se mantiene el criterio original: sólo aparece si la página declara sus dos idiomas, para no prometer traducciones inexistentes. `static_href` evita que Polyglot reescriba el enlace hacia el idioma activo, que es justo lo contrario de lo que un conmutador necesita. {%- endcomment -%} {% assign active_lang = site.active_lang | default: page.lang | default: site.default_lang | default: "es" %} {% assign switcher_languages = page.available_languages %} {% if page.translation_languages %} {% assign switcher_languages = page.translation_languages %} {% endif %} {% assign language_order = "es,en" | split: "," %} {% assign switcher_label = "Idioma" %} {% if active_lang == "en" %}{% assign switcher_label = "Language" %}{% endif %} {%- comment -%} Ruta canónica en el idioma por defecto, sin el prefijo del idioma activo.
