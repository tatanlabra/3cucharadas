# Atribución para piezas de difusión

Plantillas locales; no se ha enviado ni publicado ninguna pieza.

| Nivel del artículo | ES | EN |
|---|---|---|
| `no_ai` | Preparé este artículo sin IA. | I made this article without AI. |
| `some_ai` | Preparé este artículo con ayuda de IA. Así la uso: enlace a mi política. | I used AI to help prepare this article. How I use it: link to my policy. |
| `fully_autonomous` | Generé este artículo íntegramente con IA. | I generated this article entirely with AI. |
| `not_disclosed` | Aún no he declarado aquí mi uso de IA. | I have not declared my AI use here yet. |

El nivel global no sustituye la procedencia por componente. No afirmar revisión humana ni atribuir una herramienta concreta sin registro. Para imágenes nuevas de esta entrega: «Creé esta ilustración con ImageGen de OpenAI mediante Codex». Usar «Hecho con ChatGPT» solo cuando conste ese origen. Los gráficos estadísticos proceden de Python/Matplotlib y datos agregados, no de generación de imágenes.

La declaración histórica `some_ai` corresponde a la declaración del autor; no reconstruye intervenciones desconocidas en el texto. La política bilingüe vive en `_pages/ai-transparency*.md`. El exportador DEV se valida solamente con `--dry-run`.
